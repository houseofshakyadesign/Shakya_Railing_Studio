# Live Videos Directory

Place your live railing videos, fabrication recordings, and installation footage in this folder.

### 📁 Folder Structure:
- `public/videos/`
  - `hero-bg.mp4` / `hero-bg.webm` — Background video for Hero section.
  - `railings/` — Video previews and live walkthroughs for individual railing models (e.g. `r01.mp4`, `r02.mp4`).

### 🎬 Recommended Formats & Settings:
- **Format**: MP4 (H.264 / AAC) and WebM (VP9) for maximum browser compatibility.
- **Resolution**: 1080p (1920×1080) or 720p (1280×720).
- **Target Size**: Under 5MB–10MB for fast web streaming.
- **Access in App**: `src="/videos/hero-bg.mp4"` or `src="/videos/railings/r01.mp4"`.
